## 🌟 Overview

This repository houses the personal portfolio, engineering platform, and digital studio showcase of **Mubarak Atheeb**. Built with an **Express.js** backend and an immersive **Three.js WebGL** 3D constellation engine, it combines bleeding-edge web graphics with real-world enterprise engineering — featuring cloud database logging, instant Telegram phone notifications, seamless automatic voiceover introduction, and an interactive in-browser cyber terminal.

## 🔌 API Reference

### Profile & Content
- `GET /api/profile` &mdash; Returns complete biographical information, leadership positions, skills, and projects.
- `GET /api/projects` &mdash; Returns projects catalog; supports category filtering via `?category=Web` or `?category=AI`.
- `GET /api/stats` &mdash; Returns server uptime, total messages count, connected database engine, and Telegram status.

### Contact & Messaging
- `POST /api/contact` &mdash; Validates contact inquiries, inserts them into Supabase PostgreSQL, dispatches an instant Telegram notification, and saves to local storage.
  ```json
  // Request Body
  {
    "name": "Alexander Vance",
    "email": "alex.vance@example.com",
    "subject": "AI Project Collaboration",
    "message": "Hi Mubarak, we would love to discuss an engineering collaboration."
  }
  ```
- `GET /api/messages` &mdash; Retrieves received inquiries (supports Supabase with local fallback).

## 📦 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v18.0.0 or higher)
- [npm](https://www.npmjs.com/) (v9.0.0 or higher)

### 1. Clone Repository
```bash
git clone https://github.com/atheeb11/Mubarak_Atheeb.git
cd Mubarak_Atheeb
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Configure Environment Variables
Copy the example environment file:
```bash
cp .env.example .env
```
Populate `.env` with your desired credentials:
```env
PORT=3000

# Supabase PostgreSQL (Optional)
SUPABASE_URL=https://your-project.supabase.co
SUPABASE_KEY=your-supabase-anon-key

# Telegram Bot Notifications (Optional)
TELEGRAM_BOT_TOKEN=your-telegram-bot-token
TELEGRAM_CHAT_ID=your-numeric-chat-id
```

### 4. Start the Application
```bash
# Production start
npm start

# Development mode
npm run dev
```
Open your browser and visit: **`http://localhost:3000`**

## ☁️ Deployment Guide

### Deploying to Vercel (1-Click)
1. Fork or push this repository to your GitHub account.
2. Sign in to [Vercel](https://vercel.com/) and click **"New Project"**.
3. Select `Mubarak_Atheeb` from your GitHub repositories and click **Import**.
4. In **Environment Variables**, add:
   - `TELEGRAM_BOT_TOKEN`
   - `TELEGRAM_CHAT_ID`
   - `SUPABASE_URL` *(optional)*
   - `SUPABASE_KEY` *(optional)*
5. Click **Deploy**. Vercel will build and serve your portfolio with global Edge CDN caching and automatic HTTPS.
