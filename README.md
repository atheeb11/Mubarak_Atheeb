# 🌐 Mubarak Atheeb — 3D Cybernetic Portfolio

An ultra-modern, high-performance, 3D WebGL interactive personal portfolio and agency showcase engineered for **Mubarak Atheeb** (Informatics Engineering Student at Universitas Nusa Putra, AWS Student Builder Community Leader, and Founder at InkBit Digital Studio).

Powered by **Express.js** backend architecture, **Three.js** 3D WebGL graphics, and **Cyber Glassmorphism** UI.

---

## 🚀 Key Highlights & Features

- **3D Interactive WebGL Hero Canvas**:
  - 1,200+ particle constellation with reactive mouse inertia.
  - Floating 3D wireframe cybernetic core (Icosahedron & Octahedron) and Torus Knot.
  - Dynamic 3D lighting that tracks mouse velocity and cursor coordinates.
- **Free-Standing 3D Cutout Hero Portrait**:
  - High-res portrait of Mubarak Atheeb in his signature maroon academic blazer.
  - Free-standing silhouette with atmospheric back-aura, holographic floor pedestal, and orbital rings.
  - Floating 3D status badges with parallax depth tracking:
    - *AWS Student Builder Community Leader*
    - *President @ AWS Student Builder Club Nusa Putra*
    - *Ambassador @ One World Youth Movements*
    - *Ambassador @ International Diplomats*
    - *Founder @ InkBit Digital Studio*
- **Automatic Dual-Tier Voiceover Introduction**:
  - Pre-rendered audio track (`/audio/intro.wav`) matching Mubarak's personalized greeting.
  - Automatic playback engine on site open or refresh with Web Speech API (`speechSynthesis`) fallback.
  - Quick-action floating controls to pause, replay, or toggle sound effects.
- **Interactive Tech Matrix & Skills Showcase**:
  - 15 core skills with official Devicon brand logos and FontAwesome icons.
  - Continuous 3D infinite marquee ribbon streaming brand logos.
  - Interactive 3D tilt cards with SVG circular radial meter gauges and category filter tabs (*Frontend & UI*, *Backend & Data*, *AI, Data & Hardware*).
- **Featured Works & Engineering Projects**:
  - Responsive cards with SVG preview illustrations and live modal breakdowns.
  - Filterable by domain: *Web Development*, *AI / Data Systems*, and *Hardware Architecture*.
- **Interactive 3D Developer Console (Terminal)**:
  - Functional in-browser CLI console supporting commands like `help`, `about`, `leadership`, `aws`, `roles`, `skills`, `projects`, `experience`, `education`, `certs`, `contact`, `hire`, `whoami`, `clear`, `matrix`.
  - Up/Down arrow command history navigation and tab completion.
- **Curriculum Vitae Modal (`#printable-cv`)**:
  - Complete academic, professional, and extracurricular profile.
  - Formatted for print and instant PDF export via browser `@media print`.
- **Express.js API Engine**:
  - `GET /api/profile`: Delivers dynamic profile and biography dataset.
  - `GET /api/projects`: Filterable project catalog.
  - `GET /api/stats`: Dynamic server uptime, visit statistics, and status.
  - `POST /api/contact`: Form submission handling with JSON file persistence (`data/messages.json`) and instant feedback.
  - `GET /api/messages`: Ledger of incoming transmissions.

## 📦 Getting Started

### 1. Clone the Repository
```bash
git clone https://github.com/atheeb11/Mubarak_Atheeb.git
cd Mubarak_Atheeb
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Start the Express Server
```bash
npm start
```
Or for development with auto-reload:
```bash
npm run dev
```

### 4. Open in Browser
Navigate to:
```
http://localhost:3000
```
