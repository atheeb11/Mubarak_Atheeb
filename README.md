# 🌐 Mubarak Atheeb — 3D Interactive Portfolio

An ultra-modern, high-performance, 3D WebGL interactive personal portfolio and agency showcase engineered for **Mubarak Atheeb** (Informatics Engineering Student at Universitas Nusa Putra & Founder at InkBit Digital Studio).

Powered by **Express.js** backend architecture, **Three.js** 3D WebGL graphics, and **Tailwind & Cyber Glassmorphism** UI.

---

## 🚀 Key Highlights & Features

- **3D Interactive WebGL Hero Canvas**:
  - 1,200+ particle constellation with reactive mouse inertia.
  - Floating 3D wireframe cybernetic core (Icosahedron & Octahedron) and Torus Knot.
  - Dynamic 3D lighting that tracks mouse velocity and cursor coordinates.
- **3D Holographic Portrait Card**:
  - High-res portrait of Mubarak Atheeb in his signature maroon academic blazer.
  - Perspective-based mouse tilt physics and specular sheen highlights.
  - Orbiting orbital rings and floating status badges (*Founder @ InkBit*, *AI / ML Diplomas*, *Universitas Nusa Putra*).
- **Interactive 3D Developer Console (Terminal)**:
  - Functional in-browser CLI console supporting commands like `help`, `about`, `skills`, `projects`, `experience`, `education`, `certs`, `contact`, `hire`, `whoami`, `clear`, `matrix`.
  - Up/Down arrow command history navigation.
- **Web Audio FX Synthesizer**:
  - Cyber acoustic effects synthesized purely in real-time using browser **Web Audio API** (no external audio files required).
  - Sound effects toggleable from the floating HUD controller.
- **Express.js API Engine**:
  - `GET /api/profile`: Delivers dynamic profile and biography data.
  - `GET /api/projects`: Filterable project catalog.
  - `GET /api/stats`: Dynamic server uptime, visit statistics, and status.
  - `POST /api/contact`: Form submission handling with JSON file persistence (`data/messages.json`) and instant feedback.
  - `GET /api/health`: Express API health monitor.
- **Atmosphere Switcher**:
  - Toggle between *Obsidian Cyan* and *Deep Violet* cyberpunk color palettes.

## 📦 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Start the Express Server
```bash
npm start
```
Or for development:
```bash
npm run dev
```

### 3. Open in Browser
Open your browser and navigate to:
```
http://localhost:3000
```
